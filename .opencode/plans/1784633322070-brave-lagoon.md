**Branch:** `feat/starpm-v4-universe` off `OMEGA`. Leave the pre-existing uncommitted `.omo/` / `.opencode/` / task-report WIP untracked and untouched (not part of this effort).

**TDD (every code task):** RED (write the failing regression anchor or unit test first; run; capture the assertion + reason it fails), GREEN (smallest change to flip it; re-run; capture), then the universal wave gate. No production code before its failing test exists in the notepad. Exemptions (asset copy, pure docs, JSON-hash additions) are justified inline.

**Universal wave gate (run from repo root at the END of every wave; ALL must hold):**
```
python3 Validators/test_regression_anchors.py --verbose
#   expect: exit 0; "0 failed"; passed >= 48 baseline + (new anchors added through this wave)
python3 Validators/verify_wave0_baseline.py
#   expect: exit 0; "7/7 snapshot tasks unchanged"; "untouched-file code hashes: unchanged"
```
plus the wave-specific proof named in that wave. The 7-task output diff is the authoritative no-regression proof (we intentionally edit shared files, so their code hashes legitimately change; the code-hash guard only covers files NOT in this wave's planned surface, catching accidental edits).

**Commit strategy (atomic, gate-gated):**
- One commit per task row: `starpm(wN): <imperative> [<file>]`. Test-first pairs commit as two commits (`...: RED anchor <name>` then `...: GREEN <impl>`).
- A wave is not "done" and the next wave does not start until its gate is green. Tag each green gate: `git tag starpm-wN-green`.
- No commit may leave the universal gate red. If a task reddens a baseline anchor or the 7-task diff, revert and fix before proceeding.
- Final: PR `feat/starpm-v4-universe` -> `main` with the W9 proof report attached.
